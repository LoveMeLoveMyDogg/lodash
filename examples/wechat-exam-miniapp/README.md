# 每日考编刷题助手（微信小程序 Vue 版）

这是一个基于 **uni-app + Vue 3** 的微信小程序示例工程，只面向微信小程序端，不包含网页 / H5 页面。

## 功能覆盖

- 首页固定展示当天 10 道题（公基 5 道 + 综合能力 5 道）。
- 首次启动预生成 3 天共 30 道题，并缓存到本地 `exam_bank`。
- 点击“再来 10 道”后，立即本地生成 10 道新题，并替换题库中最旧的 10 道题。
- 支持即时判题、收藏、错题本、设置页、模型状态展示。
- 错题本最多缓存 200 题，超过后自动滚动淘汰旧数据。
- 订阅消息逻辑已封装，便于接入微信订阅消息能力。

## 目录说明

```text
src/
├── components/       # 通用组件
├── constants/        # 常量配置
├── pages/            # 页面
├── services/         # AI 生成与通知服务
├── store/            # 题库状态管理
└── utils/            # 存储、日期等工具函数
```

## 运行方式

1. 在该目录安装依赖。
2. 运行 `npm run dev:mp-weixin`。
3. 使用 HBuilderX 或微信开发者工具打开编译产物。

## Transformers.js 接入说明

当前 `src/services/aiGenerator.js` 预留了本地模型加载接口，并提供了离线模板兜底逻辑，便于你在真机环境中替换为实际的 Transformers.js 小程序模型推理代码。
